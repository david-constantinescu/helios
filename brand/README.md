# Helios brand assets

- `helios-logo-original.png` — the supplied logo (white on black, 800×1000).
- `helios-mark.png` — white mark on transparent, tightly cropped (used in-app as a template image).
- `helios-mark-black.png` — black mark on transparent, for light backgrounds, docs and print.
- `helios-mark-padded.png` — white mark centred on a transparent 1024 square.
- `helios-app-icon-1024.png` — the iOS app icon (white mark on black); also in `ios/.../AppIcon.appiconset`.
- `helios-app-icon-light-1024.png` — inverted variant for light contexts.
- `helios-oled-64.png` — 1-bit 64 px mark for the Crew Hub OLED splash (`hub/crewhub/logo.py`).
- `sizes/` — app icon at 16–512 px for web, docs and other platforms.
